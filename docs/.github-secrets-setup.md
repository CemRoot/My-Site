# GitHub Secrets Setup Guide

## Add API Keys to GitHub Repository

1. Go to your repository: https://github.com/CemRoot/My-Site

2. Settings → Secrets and variables → Actions

3. Click "New repository secret" and add:

### Secret 1: GROQ_API_KEY
```
Name: GROQ_API_KEY
Value: your_groq_api_key_here
```

### Secret 2: FIRECRAWL_API_KEY
```
Name: FIRECRAWL_API_KEY  
Value: your_firecrawl_api_key_here
```

### Secret 3: NEXT_PUBLIC_SUPABASE_URL
```
Name: NEXT_PUBLIC_SUPABASE_URL
Value: your_supabase_project_url_here
Example: https://abc123xyz.supabase.co
```

### Secret 4: NEXT_PUBLIC_SUPABASE_ANON_KEY
```
Name: NEXT_PUBLIC_SUPABASE_ANON_KEY
Value: your_supabase_anon_key_here
```

### Secret 5: SUPABASE_SERVICE_ROLE_KEY
```
Name: SUPABASE_SERVICE_ROLE_KEY
Value: your_supabase_service_role_key_here
⚠️ CRITICAL: This is a SECRET key - never share publicly!
```

## Test the Workflow

After adding secrets:
1. Go to Actions tab
2. Find "Scrape Tech News" workflow
3. Click "Run workflow" → Run workflow button
4. Wait ~2-3 minutes
5. Check Supabase Dashboard → tech_news_articles table for new articles

## Schedule

The workflow runs automatically:
- Monday-Friday only (no weekends - Nuvemmag doesn't publish)
- 3 times per day: 08:00, 14:00, 20:00 UTC
- Manual trigger also available via Actions tab

## How It Works

```
GitHub Actions → Scrape News → Translate → Save to Supabase PostgreSQL
                                              ↓
                                         Website fetches from API
                                              ↓
                                         Users see latest news!
```

**No git commits needed!** Articles are stored directly in Supabase database.
