# Bug Fixes - October 12, 2025

## Overview
Fixed multiple issues in the Tech News section related to URL formatting, slugs, content filtering, and UI/UX.

---

## ✅ Fixed Issues

### 1. Original Article Source Link Malformed ❌ → ✅

**Problem:**
- The "Original Article Source" link was displaying as: `[https://fortune.com/...](https://fortune.com/...)`
- Clicking it would redirect to: `http://localhost:3001/tech-news/[https://fortune.com/...]`

**Solution:**
- Updated the URL extraction regex in `scripts/news-scraper.js` (lines 301-313)
- Changed regex to properly extract URL from markdown link parentheses: `\[([^\]]+)\]\((https?:\/\/[^\)]+)\)`
- Now extracts the URL from `mdLinkMatch[2]` (the parentheses part) instead of brackets
- Created a migration script to fix all 16 existing articles in the database

**Result:**
- Original source URLs are now clean: `https://fortune.com/2025/10/04/jeff-bezos-amazon-openai-sam-altman-ai-bubble-tech-stocks-investing/`
- Links work correctly and redirect to external sources

---

### 2. Article URL Slugs in Turkish ❌ → ✅

**Problem:**
- Article slugs were in Turkish: `jeff-bezos-sam-altman-ile-ayni-fikirde-bir-yapay-zeka-balonunun-icindeyiz-ama-faydalari-devasa-olacak`
- URLs looked unprofessional and didn't match the English content

**Solution:**
- The scraper already had `generateSlug()` function (lines 58-66) that creates URL-friendly slugs
- The scraper was already calling `generateSlug(translatedArticle.title)` (line 476)
- However, existing articles had old Turkish slugs
- Created a migration script to regenerate all slugs from translated English titles

**Result:**
- All article slugs are now in English: `jeff-bezos-is-in-agreement-with-sam-altman-we-are-in-an-artificial-intelligence-bubble-but-the-benef`
- Clean, professional-looking URLs that match the content

---

### 3. Nuvemmag Logo Appearing in Articles ❌ → ✅

**Problem:**
- The Nuvemmag logo image was appearing within article content
- Showed as: `<img src="https://cdn.prod.website-files.com/.../NuvemMag-Logo.png">`

**Solution:**
- Enhanced content filtering in `scripts/news-scraper.js` (lines 277-293)
- Added filters to remove lines containing:
  - `nuvemmag.com`
  - `NuvemMag-Logo`
  - `cdn.prod.website-files.com/664e54b1b2f127a2d94fd963` (their CDN path)
- These filters work during the scraping process

**Result:**
- Nuvemmag branding is completely removed from article content
- Only the translated article text and relevant images remain

---

### 4. "Back to Tech News" Button Not Clickable ❌ → ✅

**Problem:**
- The button was not clickable due to being covered by the fixed navbar
- Padding issue caused the button to be in the navbar's overlap zone

**Solution:**
- Updated `src/components/TechNewsDetail.tsx`
- Changed container padding from `py-20` to `pt-24 pb-20` (line 171)
- Added `relative z-10` to the button (line 177)
- Applied same padding fix to loading and error states (lines 137, 155)

**Result:**
- Button is now fully clickable with proper spacing from the navbar
- Consistent layout across all page states
