## 🗄️ Database

### [supabase-schema.sql](./supabase-schema.sql)
SQL schema for the newsletter subscribers table in Supabase (Postgres).

**To use:**
1. Go to Supabase Dashboard → SQL Editor
2. Copy contents of this file
3. Run the SQL query
4. Newsletter table will be created with Row Level Security (RLS)
